# AI Maintenance Workspace

This directory reserves repository space for future automated knowledge-maintenance tooling. No analyzer, review process, or other automation exists yet.

## Directories

- `changes/` — machine-generated records describing actual repository changes.
- `reviews/` — knowledge-review results produced by future automated review processes.
- `state/` — persistent automation state, such as the last processed commit.

## Source of truth

Git and the project files are authoritative. The `Knowledge/` vault is derived project context for people and tools; it is not the source of truth.

Change records should be generated by examining actual Git and project state (for example, commits and changed files), rather than relying solely on an AI's self-report of what it changed. Records should not claim changes that cannot be verified from that state.

NotebookLM integration is intended to be added later. It is not implemented here. These directories are placeholders only; do not infer that any automation currently exists.
